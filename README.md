# sheet-sniper-site

[Sheet Sniper](https://gumroad.com/l/ieica) tanıtım sayfası ve gizlilik
politikası. GitHub Pages ile yayınlanıyor:

- https://onurgndgdu.github.io/sheet-sniper-site/
- https://onurgndgdu.github.io/sheet-sniper-site/privacy.html

Bu iki adres Google OAuth izin ekranına homepage ve privacy policy olarak
girili, yani çalışır durumda kalmaları gerekiyor.

**Burası yalnızca yayın hedefi.** Sayfaları burada düzenleme — kaynağın tek
doğru yeri `onurgndgdu/sheet-sniper` deposundaki `site/` klasörü, buraya
`./tools/publish-site.sh` ile gönderiliyor. Burada yapılan değişiklik bir
sonraki yayında sessizce üzerine yazılır.

Ayrı depo olmasının sebebi: ürün deposu tescilli ve private, ücretsiz GitHub
hesabı private depodan Pages yayınlamıyor. Public yapmak kaynağı açığa
çıkarırdı; yalnızca zaten herkese açık olması gereken iki sayfa burada.
